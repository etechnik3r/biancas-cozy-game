# Biancas Leseecke

Ein ruhiges Cozy-Puzzle für den Handy-Browser: Bücher, Pflanzen und Teekannen in Regale sortieren und mit jedem gelösten Regal neue Tapeten und Regale zum Einrichten freischalten. Gebaut von Bastian für Bianca.

## Stand
In Arbeit. Spielbar mit Speichern, Begrüßung und Einrichten (Themen, Tapeten, Regale). Es fehlt noch der Sound.

## Aufbau
| Datei | Inhalt |
|---|---|
| `index.html` | Das Spiel – eine Datei, keine Abhängigkeiten |
| `musterblatt.html` | Grafik-Musterblatt mit allen Gegenständen zur Stilabstimmung |
| `docs/konzept.md` | Spielkonzept, verbindliche Grundlage |
| `docs/offene-punkte.md` | Offene Fragen, nächste Schritte, Ideen für später |
| `CHANGELOG.md` | Alle Änderungen, neueste oben |
| `CLAUDE.md` | Arbeitsanweisungen für die Entwicklung mit Claude |

## Spielen
`index.html` im Handy-Browser öffnen. Es wird kein Server und keine Internetverbindung benötigt.

## Arbeitsweise
Siehe `CLAUDE.md`. Kurz: Änderungen in kleinen Schritten, jede Änderung im Changelog, bei Unklarheiten vorher nachfragen, am Ende jeder Sitzung pushen.
